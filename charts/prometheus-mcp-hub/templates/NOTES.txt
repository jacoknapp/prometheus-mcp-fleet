{{- if gt (int .Values.replicaCount) 1 }}

replicaCount={{ .Values.replicaCount }}. Read this before relying on it:
  A spoke tunnel is pinned to ONE hub replica and there is deliberately no
  hub-to-hub forwarding. Credential state is shared (it is one Secret), but tunnels
  are not. Every replica must be individually reachable from outside the cluster and
  every spoke must list all {{ .Values.replicaCount }} addresses in hub.endpoints. Putting several
  replicas behind one Service does NOT give you HA; it gives you a fleet where each
  cluster is visible to exactly one replica.
{{- end }}

  An automatic weekly rollout across a fleet is a fleet-wide outage delivery
  mechanism, and the hub is the single point of failure for every agent. The job
